# autonomous-dev-control-plane

A clean-room second-generation autonomous software-development control plane.

This repository is intentionally starting from a minimal foundation. The v1 autonomous-development system in `RayZhang2024/ML-AMstress` is reference evidence and a source of lessons, not code to be copied wholesale.

Development begins with a design-only Phase 0 covering the trusted core, structured contracts, state machine, semantic review boundary, repair policy, and self-modification/bootstrap model before any autonomous worker or GitHub Actions workflow is implemented.
